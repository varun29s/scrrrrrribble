<h1>🎨 Scrrrrrribble</h1>
<p>A real-time multiplayer drawing and guessing game inspired by Skribbl.io. Players create or join game rooms, draw randomly selected words, chat with others, and compete on a live leaderboard.</p>
<p><img src="https://img.shields.io/badge/Node.js-18+-green" alt="Node.js"><br><img src="https://img.shields.io/badge/Express.js-Backend-black" alt="Express"><br><img src="https://img.shields.io/badge/Socket.IO-Real--Time-blue" alt="Socket.IO"><br><img src="https://img.shields.io/badge/License-MIT-yellow" alt="License"></p>
<hr>
<h2>🚀 Features</h2>
<ul>
<li>🎨 Real-time collaborative drawing</li>
<li>👥 Multiplayer game rooms</li>
<li>💬 Live chat system</li>
<li>✏️ Word selection for the drawer</li>
<li>⏱️ Countdown timer</li>
<li>🏆 Automatic scoring &amp; leaderboard</li>
<li>🎭 Avatar selection</li>
<li>🔗 Room invite codes</li>
<li>📱 Responsive UI</li>
<li>⚡ Real-time synchronization using Socket.IO</li>
</ul>

<h2>⚙️ Installation</h2>
<h3>Clone Repository</h3>
<pre><code class="language-bash">git clone https://github.com/varun29s/scrrrrrribble.git
cd scrrrrrribble
</code></pre>
<h3>Install Dependencies</h3>
<pre><code class="language-bash">npm install
</code></pre>
<h3>Start Development Server</h3>
<pre><code class="language-bash">npm run dev
</code></pre>
<p>or</p>
<pre><code class="language-bash">node server.js
</code></pre>
<hr>
<h2>🌐 Local URL</h2>
<pre><code>http://localhost:3000
</code></pre>

<h2>📡 Socket.IO Events</h2>
<h3>Client → Server</h3>
<ul>
<li>create-room</li>
<li>join-room</li>
<li>start-game</li>
<li>draw</li>
<li>guess</li>
<li>clear-canvas</li>
<li>disconnect</li>
</ul>
<h3>Server → Client</h3>
<ul>
<li>room-created</li>
<li>room-joined</li>
<li>player-update</li>
<li>game-start</li>
<li>drawing</li>
<li>leaderboard-update</li>
<li>game-over</li>
</ul>
<hr>
<h2>🎮 How to Play</h2>
<ol>
<li>Enter your username.</li>
<li>Create a room or join using an invite code.</li>
<li>Wait for players to join.</li>
<li>The drawer chooses one of the given words.</li>
<li>Draw the selected word.</li>
<li>Other players guess using the chat.</li>
<li>Earn points for correct guesses.</li>
<li>Highest score wins.</li>
</ol>
